# Wildfire Detection System 🔥

A **deep learning model** that detects wildfires from aerial/satellite images using Convolutional Neural Networks (CNN).

## Overview
Wildfires cause massive destruction every year. This project uses computer vision to automatically identify wildfire presence in images — enabling early detection and faster response.

## Model Architecture
- **Type:** Convolutional Neural Network (CNN)
- **Framework:** TensorFlow / Keras
- **Task:** Binary image classification (Wildfire / No Wildfire)
- **Iterations:** Multiple versions trained and evaluated (v3, v5) to optimize accuracy

## How to Run
1. Clone the repo
2. Install requirements:
```bash
pip install tensorflow keras numpy matplotlib
```
3. Open `wildfire_detection_v5_perfect.ipynb` in Jupyter Notebook
4. Run all cells
